# 📥 How to Download & Use

## Option 1: Download ZIP (Easiest)

1. Go to: https://github.com/RIgbycat11/mc-mod
2. Click **Code** button (green button, top right)
3. Click **Download ZIP**
4. Extract the ZIP file on your computer
5. Navigate to the `todo-app` folder
6. **Double-click `index.html`** to open in your browser

✅ **That's it! The app works offline with no installation needed.**

---

## Option 2: Clone with Git (For Developers)

If you have Git installed:

```bash
git clone https://github.com/RIgbycat11/mc-mod.git
cd mc-mod/todo-app
```

Then open `index.html` in your browser.

---

## Option 3: Use Online (No Download)

1. Visit: https://github.com/RIgbycat11/mc-mod/tree/dev/todo-app
2. Click on `index.html`
3. Click the **Raw** button
4. Copy the URL from your browser's address bar
5. Paste into: https://htmlpreview.github.io/?https://raw.githubusercontent.com/RIgbycat11/mc-mod/dev/todo-app/index.html
6. App runs live in browser!

## Troubleshooting

### App won't open?
- Make sure you have all 3 files in the same folder: `index.html`, `styles.css`, `app.js`
- Try a different browser (Chrome or Firefox recommended)
- Clear browser cache and refresh

### Tasks not saving?
- Check if localStorage is enabled in your browser settings
- Try incognito/private mode
- Clear cookies and cache

### App runs slowly?
- Close other browser tabs
- Refresh the page (Ctrl+R or Cmd+R)
- Try a different browser
