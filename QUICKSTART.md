# Quick Start Guide

## 🚀 Get Started in 60 Seconds

### Step 1: Download
👉 Go to https://github.com/RIgbycat11/mc-mod/releases or click **Code → Download ZIP**

### Step 2: Extract
📂 Unzip the downloaded file

### Step 3: Open
🌐 Double-click `todo-app/index.html` in your browser

### Done! 🎉
Your to-do list app is now running. Tasks save automatically.
